### 1. Backend API Integration Context (Public / Unauthenticated)
All product retrieval endpoints must function without user authentication tokens.

- **Get All Products / Filtered Products**:
  - `GET http://localhost:3000/api/products`
  - Optional Query Parameters: `page`, `limit`, `size`, `color`, `category`, `brand`, `minPrice`, `maxPrice`, `search`
  - Example: `GET http://localhost:3000/api/products?page=1&limit=20&brand=Nike,Adidas&category=sports&size=US 10&minPrice=50&maxPrice=250`

- **Get Product By ID (PDP)**:
  - `GET http://localhost:3000/api/products/PRODUCT_ID_TO_FETCH_DETAILS`


### 2. Product Listing Page (PLP) — `app/shop/page.tsx`
- **Header & Search Bar**: Top bar displaying "Shoes Catalog", a subtitle description, and a search input with a search button.
- **Sidebar Filters**:
  - **Brand Filter**: Clickable pills/buttons for brands (e.g., All Brands, Nike, Adidas, Asics, Jordan, New Balance, Puma).
  - **Category Filter**: List categories (All Categories, Basketball, Lifestyle & Sneakers, Running, Training & Gym).
  - **Shoe Size (US)**: Grid selector for sizes (All, 7 through 12, including halves).
  - **Colorway**: Interactive color circles/swatches (All Colors, Red, Black, White, Purple, Grey, Blue, Orange, Green).
  - **Price Range**: Dual-range slider or min/max price inputs (e.g., ₹0 to ₹25,000).
  - **Reset All Filter Button**: Instantly clears all query parameters and resets state.
- **Catalog Grid & Sorting**:
  - Sort Dropdown: Options for **Featured**, **Price: Low to High**, **Price: High to Low**.
  - Product Cards displaying discount badges (e.g., "10% OFF"), stock status ("In Stock"), brand name, shoe title, colorways count, available size range, and pricing (current price & strikethrough original price) with an **"Add"** button.

---

### 3. Product Detail Page (PDP) — `app/shop/[id]/page.tsx`
- **Breadcrumb Navigation**: "Back to Shoes" link.
- **Media Gallery Section**:
  - Main high-resolution image viewer.
  - Thumbnail switcher for `galleryImages` below or beside the main container.
- **Product Details Section (Right Column)**:
  - Brand name tag, category, title, average rating with review counts (e.g., `4.8 (74 reviews)`), and stock availability badge (`In Stock & Ready to Ship`).
  - Prominent pricing display.
  - Product description block.
  - **Colorway Selector**: Interactive chips representing available colors.
  - **Size Selector**: Grid of size chips with an active selected state and a "Size Chart & Fit Guide" link.
  - **Quantity Selector**: Stepper controls (`-` `1` `+`).
  - **Action CTAs**: **"Add to Cart"** button and **"Buy Now with QR Code"** secondary action button.
  - **Trust Badges**: "100% Authentic", "Free Shipping", and "Easy Returns" icons.
- **Footwear Specifications Card**: Accordion or grid box detailing Upper Material, Midsole Cushioning, Shoe Weight, and SKU Reference.
