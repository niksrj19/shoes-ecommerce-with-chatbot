Build a production-ready, interactive **Cart System & Slide-over Cart Drawer** for the shoe retail application **SoleVault** in Next.js (App Router, TypeScript, Tailwind CSS), integrating with a Node.js backend running on `http://localhost:3000`.

---### 1. Guest Session & Authentication Architecture- **Session ID (`sessionId`)**: Guest users can build a shopping cart without logging in. The application must generate or retrieve a unique `sessionId` stored in cookies (e.g., `sessionId`).- **Headers & Cookie Transmission**:  - Every cart API request must automatically transmit both `sessionId` and `accessToken` (if logged in) via cookies and headers.  - The backend dynamically identifies whether the request belongs to a guest user or an authenticated account.- **Guest-to-User Cart Merge on Login**:  - Immediately upon a successful user login/authentication event, trigger the merge endpoint:    - **Endpoint**: `POST http://localhost:3000/api/cart/merge`    - **Headers**: Requires valid `accessToken` (`Bearer <token>`) and `sessionId`.    - **Behavior**: Merges the items from the active guest session into the authenticated user's account cart, then syncs state.

---### 2. Backend Cart API Contracts1. **Get Cart**:   - `GET http://localhost:3000/api/cart/`   - Authorization: Optional (supports guest & authenticated users).2. **Add Item to Cart**:   - `POST http://localhost:3000/api/cart/items`   - Payload:     ```json
     {
       "productId": "prod_12345",
       "size": "US 9",
       "color": "Bred Red/Black",
       "quantity": 1
     }
     ```3. **Update Item Quantity in Cart**:   - `PUT http://localhost:3000/api/cart/items`   - Payload:     ```json
     {
       "productId": "prod_12345",
       "size": "US 9",
       "color": "Bred Red/Black",
       "quantity": 2
     }
     ```4. **Delete Item from Cart**:   - `DELETE http://localhost:3000/api/cart/items`   - Payload:     ```json
     {
       "productId": "prod_12345",
       "size": "US 9",
       "color": "Bred Red/Black"
     }
     ```5. **Clear Entire Cart**:   - `DELETE http://localhost:3000/api/cart/`   - Authorization: Optional.

---### 3. UI Requirements & Visual Layout (Referencing Design Mockups)1. **Slide-over Cart Drawer (`CartDrawer.tsx`)**:   - Triggers seamlessly from both the Product Listing Page (PLP) "Add" buttons and the Product Detail Page (PDP) "Add to Cart" button.   - **Drawer Header**: Displays total item count (e.g., `Cart (3)`) and a close `X` button.   - **Cart Item Card**:     - Product thumbnail image, product title, selected variant text (`US 8 • court purple`), price per item.     - Stepper control (`-` `1` `+`) to trigger quantity updates.     - Trash icon button to delete specific item variant.   - **Summary Footer**:     - Calculated breakdown: Subtotal, GST (18%), Standard Delivery (`Free Delivery`), and **Total Amount (INR)**.     - Secure payment badge.     - **"Proceed to Checkout"** CTA button navigating to `/checkout`.2. **Checkout Flow Adjustment**:   - Update the step indicator text on the Checkout page step 2 from "QR Payment" to **"Payment"** (Step 1: *Delivery Details*, Step 2: *Payment*, Step 3: *Order Confirmed*).
